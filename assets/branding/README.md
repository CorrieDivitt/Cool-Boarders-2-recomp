# Branding and catalog art

Original artwork for this project: an illustrated mountain scene, a generic
snowboarder silhouette and the project's snowflake emblem, with plain
lettering. Nothing here is taken or traced from the game, its box art, its
logo or its characters. Licensed with the rest of the project (PolyForm
Noncommercial 1.0.0).

| File | Size | Use |
|---|---|---|
| `poster_600x900.png`, `poster_1200x1800.png` | 2:3 | Tall library card. RecompLauncher **cover**; Quiver **capsule**; SteamGridDB grid |
| `hero_1920x620.png`, `hero_3840x1240.png` | 96:31 | Backdrop with no text (launchers lay the logo over it). RecompLauncher and Quiver **hero** |
| `logo_1280x400.png`, `logo_2560x800.png` | transparent | Wordmark with the emblem. RecompLauncher and Quiver **logo** |
| `header_920x430.png` | ~2.14:1 | Quiver **header** (Steam header shape) |
| `wide_1280x640.png` | 2:1 | RecompLauncher wide tile, GitHub social preview |
| `icon_512.png`, `icon_256.png`, `icon.ico` | square | App icon. RecompLauncher **icon** |

To change the art, edit `source/scene.py` and run `python3 source/make.py`
from this folder (needs Google Chrome for rendering and Pillow).
